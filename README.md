# hwatch

Run a team of AI agents that works while you're away. hwatch gives each agent a role, wakes it when there's
work for it, and keeps the whole team inside the token budget you set. It works with any LLM provider, and
your agents share what they learn through your [HiveMind](https://github.com/projectmentor/hive-mind) hive.

**Status: coming soon.** hwatch already runs HiveMind's own development every day. The public release
lands here. Star the repo to hear when it ships.

## What you get

- **A team, not a chat window.** Implementers build, reviewers review, verifiers check. Each agent sticks to
  its role and hands work to the next.
- **Any provider.** Mix Claude, Grok and other models, and pick the right model for each role.
- **A budget that holds.** Daily limits per agent and per task, so a busy day never surprises you on the bill.
- **Free.** hwatch is free and open source. Paid add-ons for HiveMind are on the way.

hwatch is a HiveMind module. Learn more at [hivemind.projectmentor.org](https://hivemind.projectmentor.org).
